# ARCHITECTURE — 시스템 구성

> 프로젝트: **회사1** · 설계 버전: **v3.1.1** · spec-format v2  
> 기술 스택과 구성, 비기능 요구사항을 어떻게 지킬지 정리한 문서다. 읽는 순서와 작업 규칙은 `AGENTS.md`.

## 1. 구성 요약

물리서버 3대 클러스터(WEB·WAS·DB), DATA NAS, 백업 장비, 메일보안 장비, 전용방화벽, 서버랙·KVM으로 구성된 온프레미스 환경에, 검증된 상용 패키지 기반의 ERP·그룹웨어 통합 시스템을 구축한다. 컨테이너 기반 확장형 구조와 무중단 배포, Non-ActiveX 멀티브라우저 웹 환경을 제공하며, 외부 금융·결재 시스템 및 내부 단위시스템과 API로 연계한다. 연중 무중단 운영, 동시 사용자 150명, 개인정보 암호화·접근 로그 관리, 공공기관 데이터 표준 준수를 전제로 한다.

## 2. 기술 스택

| 구분 | 내용 | 근거 |
|---|---|---|
| 백엔드 (언어·프레임워크·DB) | TypeScript · NestJS · PostgreSQL 16 · Next.js 14 · React 18 · TypeScript (확정 — 기능 명세에서 고름 TQ-001) | TQ-001 |

- DDL(`schema.sql`)은 PostgreSQL 16 기준으로 검증했다. 원문이 다른 DBMS를 정했으면 DDL을 그 DBMS 문법으로 옮긴다.
